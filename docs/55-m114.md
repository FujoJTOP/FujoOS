## 1. D 自然语言配置

```
"ban games during 0 to 24" → shm kind=5 → Qwen 7b → "POL=3:1;POL=4:0;POL=5:24"
  → 0x8307 nlc_set 解析 k:v 对 → cfg_set → out[0]=应用条数 → 0x8106 读回校验
  → 策略执行面: 0x6601 game_mode(1) 命中禁玩时段 → -1 (拒绝, 审计可见)
```

- 配置键: 1=anom 阈值 2=自动隔离 3=game_ban 4=ban 起始小时 5=ban 结束小时
  6=场景档案 7/8 预留。
- 策略执行钩子: gamemode.rs `fujo_game_mode` —— cfg(3)=1 且
  `hour_of_day() (PIT/360000) in [cfg(4), cfg(5))` → 拒绝。
- 规则降级: "ban" + 数字 → POL=3:1;4:start;5:end (demo 基线同判据)。

## 2. E 环境侦察

```
hw/fbw/fbh/ata/fs/rsdp/pci/kbd 摘要 → shm kind=6 → 7b "SCENE=x PROFILE=n"
  → 0x8308 env_scan: scene_code + cfg_set(6, profile) → out {profile, scene, len}
```

- 场景枚举: desktop=1 headless=2 server=3 games=4; 档案 1..4 (min..max)。
- 规则降级: desktop/2 (确定性默认, demo 基线)。

## 5. 踩坑

1. **no_std + alloc**: `[u8]::to_vec` 不可用 (无 alloc) → 固定数组 + 长度
   元组 (env_scan 场景名走 `scene_buf/sn`)。编译错误被 "警告先行" 的日志
   截断误判为成功 —— 以 `llvm-nm` 验证符号存在为准绳。
2. **服务端 POL 抽取**: 模型逐对输出 `POL=3:1;POL=4:0;...` 时 findall 只留
   最后一对 → 改为收集所有 `POL=k:v` 对再拼接。
3. **syscall 未实现是陈旧 bin**: "nr=33543 unimplemented" = 分发尚未含
   0x8307 → flatten 前必须看到 "Compiling fujo-kernel"。
