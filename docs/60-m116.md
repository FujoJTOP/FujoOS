# 60 · M116 — W9 权限域与地址空间隔离 (爆炸半径定理)

> 里程碑: M116 (阶段一 W9 · 本阶段最硬) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W9
> 一句话: **cap_exec 门升级为域 `{ cap 集合, 地址空间, 中断域 }`, 支持可撤销;
> 恶意模型输出的最坏影响被域边界界定 (爆炸半径定理可断言)**。

## 1. 域模型

| 组件 | 内容 | 门控点 |
|---|---|---|
| cap 集合 | `perm` (act 位掩码, 同 exec 槽语义) | `exec_authorized` (所有 cap_exec) |
| 地址空间 | `as_mask`: LOW=0x400000..0xC00000, HIGH=0x1000000..0x1080000 | LAUNCH 入口检查 (syscall.rs cap_exec) |
| 中断域 | `irq: bool` | 0x6D01 set_window / 0x6B04 route |
| 可撤销 | `granted=false` → 全拒, 审计 action=3, 状态可读回 | 0x8109 revoke |

- 域表 5 项:域 0 = **系统域(兼容)**——读全局 exec 槽 6 (M91/M112 语义不变),
  全地址空间, 中断可配;域 1..=4 显式域, 初始未授予, 撤销后可复用。
- 任务级绑定:`Task.domain` (已登记任务) / `BOUND_DOMAIN` (隐式单任务),
  0x8108 bind (0=解绑回系统域)。域 id 0 时所有旧行为逐字节兼容 → m115/m118/m119 零改动通过。

## 2. 接口

| 编号 | 签名 | 说明 |
|---|---|---|
| 0x8107 | dom_create(perm, as_mask, irq) -> id | 分配域 1..=4; -17 无空闲 |
| 0x8108 | dom_bind(id) | 绑定当前任务 (0=解绑) |
| 0x8109 | dom_revoke(id) | 撤销 (granted=false + 审计 action=3) |
| 0x810A | dom_info(ptr) | 读回 5×5 u64 [id, perm, granted, as, irq] |

## 3. 爆炸半径定理 (断言语义)

> 定义: 域 D = {P, A, I}。∀ 模型输出 o 解析出的动作 a/入口 e/中断配置 c:
> a ∉ P → 拒绝 (cap_exec 返回 -1 且审计); e ∉ A → 拒绝; c ∉ I → 拒绝。
> 推论: 模型输出完全恶意时, 系统受影响面 ⊆ P×A×I, 与模型规模无关。

m116_dom demo (离线, 入 fujoregress) 逐条断言:
```
domain=1 (perm=0x2C=LAUNCH|SET_CFG|ACK, as=LOW only, irq=0)
hostile: KILL=-1 ISOLATE=-1 LAUNCH@0x1000000=-1(有 LAUNCH 无 HIGH) IRQCfg=-1 aiHi=-14
auth   : SET_CFG(2,1)=0 cfg2=1        (域内授权动作生效)
revoke : rc=0 thenExec=-1 cfg2=1 infoPerm=44 granted=0 audDom=1   (全拒+审计+无副作用)
系统继续: struct 可调; 回归 11/11
```
注:LAUNCH@0x1000000 单测"地址空间门"(域有 LAUNCH perm 但缺 HIGH);
"AI 原语地址空间封闭"由 AI 原语固定收窄 (0x400000..0x800000) 承担,
高区指针一律 -14 —— 域边界 + 原语收窄 = 双层。

## 4. 踩坑 (本 M 实证)

1. **域表初始化**: `[Domain{..}; 5]` 复制初始化把所有域都置 granted=true
   → dom_create 永不满 1..=4 无空闲 → 返回 -17 → 先修初始化 (显式 5 项,
   仅域 0 granted), 撤销后的域允许复用 (`!granted` 即可, 不依赖 perm==0)。
2. **BSS 页界逐波上移**: M118 顶高 0x2000, M116 又顶高 0x2000 (尾 0x2A2E20)
   → 越界两次后直接把 load_end/pad 提至 **0x2C0000/0x1C0000** 留 W10 余量
   (约束不变: load_end = 0x100000 + pad)。skill fujoos-pitfalls 已同步。
3. **域门在 syscall 路径**: LAUNCH 入口检查放 syscall.rs `cap_exec(帧)`,
   不在 capability::fujo_cap_exec (后者无 LAUNCH 分支) —— 双向 deny 只走一条路径。

## 5. 验收

| 项 | 结果 |
|---|---|
| m116 爆炸半径 (离线) | PASS (逐条 -1/-14/0 断言) |
| fujoregress 11/11 | PASS (m115/m118/m119 在域 0 下零改动) |
| verify_ai m118 7B | PASS (AI 链路不受域门影响) |
| 兼容: 系统域 = 全局槽 6 | m115 授予/执行/审计语义不变 |

## 6. 不做 (边界, W9 收缩项)

- 未做**每域独立页表** (W11 独立地址空间才做; 本 M "地址空间" = 区域集合门控);
- 域集合不含"撤销即杀任务" (revoke 只拒后续动作, m116 证过: 无副作用);
- 中断域只门控配置原语 (M67 合并窗口/路由), 未做 IRQ 投递按域屏蔽。
