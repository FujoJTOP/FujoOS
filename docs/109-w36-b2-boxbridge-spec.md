> 一句话: **五件架构件 + 六条边界全部闭合，且每件都长在现有零件上
> （域/cap_exec/R3 帧/0x8314/审计环）—— B-2 v0 以本文为规格骨架。**

## 0. 总原则与完备性定义

**判定树**：拆得开的拆（LEGO·开源语义转录）→ 分不开的接（BOX-BRIDGE·外部能力管道）→ 接不得的出界（EXCLUDED·有名有姓）。

**完备性搬家（三级）**：语义完备性（不再要求）→ 接口完备性（动词词汇表有限可枚举）→ 声明完备性（EXCLUDED 枚举 + 能力矩阵可观测）。**FUFORALL 的"完备" = 三者合并，且只在"使用"意义下成立。**

## 1. 五件架构件

| 件 | 职责 | 现有零件复用 | 新增范围 |
|---|---|---|---|
| ① 能力注册表（Provider Registry） | `(动词 V, 平台 P, 供应商 id, 状态, 指标)` —— 盒子 = "在 Windows 上经 winword 提供 PDF 的**供应商**"，不是"转 PDF 能力" | cap_exec 域（注册 = 授权动作门槛，域 = 该供应商端口） | 注册表数据结构 + syscall 查询 |
| ② 动词词汇表（Verb Vocabulary） | 动词集 \(V = \{\) 转 PDF, 查文档, …\(\}\)，几十量级封顶 | — | 枚举表（数据为主） |
| ③ 帧协议（BOX Frames v2） | 命令进 / 结构化结果 + 状态出；复用 v2 帧头 `seq/t0/evw/crit/TTL`，盒子回包受 R3 时延裁决（陈旧/过期照旧丢弃） | `ai.rs` 帧头 + `wait_rsp` 的 crit/ttl DISCARD（M112） | 新 kind 通道（模型通道的胞弟） |
| ④ 产物检疫门（Artifact Gate） | **S1 扩展**：防越权从"动作"扩展到"产物"；盒返回值 = 不可信数据 | 审计环（新增"产物拒收"动作码） | 魔数/类型白名单 → 大小上限 → 格式校验 → 禁执行语义 |
| ⑤ 双列质量台账（Dual Ledger） | 列1 履约率（接口层：返回成功 + schema 校验）/ 列2 下游成功率（语义层 = 消费端验证）；域宽 = f(质量) | 0x8314 族（QUAL_HIT/TOTAL/UP_RUN） | 双列扩展，与模型同尺度 |

**动词调度器（Router）**：动词 V → 供应商链，优先级固定 **LEGO > BOX**——原生等价物存在时盒子永不做主路，只补缺。

## 2. 六条边界逐条解决

| 边界 | 方案 | 闭合点 |
|---|---|---|
| 1 · 能力依赖外部世界 | 换成**可替换的供应商**：任何盒子挂掉 = 该供应商缺席，动词仍可由其他供应商/原生途径服务；**只有全部供应商缺席才有缺货语义** | 单一来源锁定被消除 |
| 2 · 缺席语义 | 粒度 **per-verb × per-provider**（不是 per-box）；缺席 = **声明**（矩阵显示"零供应商"）+ 审计 + S3 可读，**不是错误码** | 与 A3 区分：模型缺席 → 规则兜底；盒供应商缺席 → 换供应商 / 声明缺货；规则**不**兜语义（规则做不了"转 PDF"）——两条降级路径写进 S3 政策，不混用 |
| 3 · 盒内盲区 | **双列度量 + 消费端验证**：履约率高 + 下游低 = "履约但语义错"——可测量、可降级的状态（供应商降权而非误判健康） | 盒内正确性不在承诺内，接口履约率 + 下游命中是度量面（与模型验证点同构但更强） |
| 4 · EXCLUDED | 出界判定 = **许可（不可再分发）× 接口（无稳定接口）** 双条件；EXCLUDED = **有名有姓的清单**（按动词枚举"为什么不可接"），不是笼统"闭源不行" | 出界完备性由**政策**保证，不由工程保证 |
| 5 · 盒产物注入面 | 产物检疫门（见件④）：返回通道拒绝 + 审计 + 计入履约台账（盒子"履约但产物坏" = 供应商劣化信号） | A1' 扩展 |
| A · 人类直用闭源应用 | 降级为"可用不原生"：帧缓冲流经同一协议对人类窗口开放（远程桌面式）；Agent = 结构化帧协议 | 与 README"loader subset"承诺对齐：**可用性满足，不是原生运行** |

## 3. 生命周期（每供应商五阶段）

1. **注册**：动词-平台-供应商三元组 + cap_exec 授权（域 = 供应商端口）
2. **验证**：黄金轨迹一次录制（参考运行）→ 回放校验 + 与 LEGO 等价物差分
3. **运行**：帧协议（复用 v2 帧头，R3 时延裁决）
4. **度量**：双列台账滚动窗 → 域宽 = f(质量)；**供应商版本变化 = 重新验证**（升级后 golden 重录）
5. **退役**：供应商下线 → 动词转向可选供应商 → 全缺则声明缺货（审计 + 矩阵可见）

## 4. 安全组合（S1×S2×S3 完整适用 + A1'）

| 层 | 对盒子 |
|---|---|
| S1 机制 | 命令通道：动词白名单 + 参数 schema + cap_exec；返回通道：产物检疫门；盒子对内核的唯一权限 = 协议接口，无其他（域天然隔离）→ **定理不变：任何盒输出 ⊆ 域 ∩ 允许产物** |
| S2 测量 | 双列台账（履约率 + 下游成功率），与模型质量同尺度、同入 0x8314 族——**域宽自动适应：盒子变坏 → 域收缩/降权** |
| S3 政策 | 哪些动词允许盒子提供 / 哪些强制 LEGO / 哪些出界——**政策即清单** |

A1–A4 逐字适用 + **A1'（产物）**：任何盒子返回的不可信数据，未经检疫门不得进入任何 Agent 工具链。

## 6. 完备性最终声明（canonical wording）

> FujoOS 在"使用"意义下完备：可拆的拆（LEGO·开源语义转录）、可接的接（BOX-BRIDGE·外部能力管道）、不可的出界（EXCLUDED·有名有姓）；**每个动词的能力状态在能力矩阵中可观测，每个供应商的缺席是声明而不是错误，每个盒子的产物在进入系统前经受检疫门**。原生运行（kernel 内装载任意程序）是政策排除项，如实声明。

## 8. v0 实现裁剪（本波范围）

| 做 | 不做 |
|---|---|
| 注册表 + 路由（LEGO > BOX > 缺货声明） | GUI 像素流（B-3/v1；人类窗口 = "可用不原生"） |
| 帧协议 v2（模型通道胞弟，首个盒 = **宿主侧供应商**，如宿主 CLI 工具经 shm 通道注册） | 真实 Windows 盒验证（v1 起；v0 只证明"内核外供应商"通路，**不取闭源语义**） |
| 双列台账（履约率先行，下游成功率 = Agent 侧验证点挂接） | 供应商版本自动重验证（v0 手动静默重录即可） |
| 检疫门最小集（魔数白名单 + 大小上限 + 禁执行） | fuzz 全谱（B-31） |
| 缺席声明（per-verb 状态 + 审计） | — |

## 9. 验收（fujoregress 双态用例）

1. **box-online**：盒供应商在线 → 动词调用成功，履约记录入台账 → PASS
2. **box-offline**：盒供应商离线 → 动词声明缺货（审计 + 矩阵可见），系统其余功能不受影响 → PASS
3. **box-badart**：盒返回畸形产物 → 检疫门拒收 + 审计（产物拒收动作码）+ 履约率记败 → PASS

## 10. 与 W34 兼容层关系（不动）

兼容层（shim 翻译）服务**人类直用闭源应用**的"可用不原生"路径；BOX-BRIDGE 服务 **Agent 使用闭源能力**。两者同属 FUFORALL，判定统一走 P1（依赖闭包 ⊆ 提供语义）→ 可翻译 → shim/LEGO；不可翻译但可接口 → BOX；不可接 → EXCLUDED。
