# 66 · W15 — ABI 冻结 + shell 扩容 + 应用管理器 (app registry)

> 里程碑: W15 (阶段二) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W15
> 一句话: **系统调用面文档化冻结 (ABI v1); shell 增 `app list`/`ls`/`cat`/`echo`
> 与 `os run <app>` 注册表启动; FUJOMULT 多模块镜像登记为应用注册表。**

## 1. ABI v1 冻结 (docs/66 即冻结文本)

- **调用约定**: x86-64 SysV: `syscall` 指令; nr in RAX, args RDI/RSI/RDX/R10/R8/R9;
  返回 RAX (+RDX 为辅 64 位对, 少数接口); 错误返回负 errno 风格; 不变式: 用户态
  只能触发注册编号, 未注册号 -> 自动失败 (-ENOSYS 路径)。
- **编号平面** (稳定分组, 详见 kernel/src/syscall.rs dispatch 注释):
  | 平面 | 范围 | 内容 |
  |---|---|---|
  | POSIX 最小面 | 0..12, 39, 57, 59 | read/write/open/close/mmap/munmap/brk/getpid/fork/execve |
  | AI 器官 | 0x7A01..0x7F01 | 泄漏/转储/权重/模型卡/会话/上下文 |
  | 意图与域 | 0x8002..0x810A | ctx 事件环 / cap 权限审计 / 域 (M116) |
  | AI 管线 | 0x8201..0x830E | 路由 / 推理 / 异常 / 计划 / NLC / R3 / 规则引擎 |
  | 设备 | 0x8A01..0x8A06 | vblk 读/写/信息 + net 信息/发送/接收 |
  | 应用管理 | 0x8B01 | app 注册表列表 (W15) |
  | 系统面 | 0x8401..0x8803 | 模型注册 fupm / ACPI / hw / 安装 / 更新 |
- **冻结条款**: 编号 + 签名 + 语义为 ABI v1; 新增只能追加编号; 语义变更
  视作不兼容 (走版本协商字段, 当前无)。验证脚本 fujoregress 全矩阵
  即回归 ABI (每个 demo 依赖固定编号语义)。

## 2. 应用管理器 (交付)

- **注册表**: FUJOMULT 多模块镜像 (BootMulti, 见 syscall.rs `is_multi`) 的第 2..n
  段经 `fujo_lib_register(name, addr, len)` 登记 (8 项); 第 1 段为主模块直接 exec。
- **内核接口**: `lib_find(name)` / `fujo_app_list(out)` (0x8B01:
  +0 count, 每项 24B = name[16] + addr u64) / `lib_count/name_at/addr_at`。
- **shell**:
  - `os run NAME` — 注册表命中 -> `set_module_override(start,len,name)` ->
    `enter_user_test` (模块快照 override; 名字/长度供 fmod 打印);
  - `app list` — 打印注册表 (name @ addr);
  - `ls` — 列出 /boot /proc /dev 固定表和 /tmp/* (tmpfs);
  - `cat <path>` — 内核态 VFS 直读 (read_kernel 绕过用户指针检查);
  - `echo <text>`。
- fujoregress: m126 case 走多模块镜像 (主要 demo m126_abi)。

## 4. 踩坑 (本波)

1. **no_std 无 to_string**: shell 打印辅助得手写 (hex_str static));
2. **module_snapshot 覆盖用的 name_ptr 必须 static** (临时数组指针悬垂);
3. **FUJOMULT 段偏移**: 段 0 = main; 段 1.. 为 registry (LIB 上限 8;
   demo 镜像构造: fujopack pack --multi 或 build-samples 注册)。
