# 76 · W20 p5 — FJFS 卷经 AHCI 背板 (真机 SATA 持久化; m135)

> 里程碑: W20 p5 (脱 QEMU 专属) · 上游: docs/75 (AHCI 驱动)
> 一句话: **FJFS 文件系统从"只认 ATA PIO (QEMU IDE)"升级为"AHCI 优先 / ATA 回退"
> 磁盘背板 —— 真机 SATA 盘上的 FJFS 卷完整读写往返 (m135 PASS: 写 15B →
> 数据簇+位图+根目录全部 AHCI 落盘 → 重开回读一致)。**

## 1. 交付

| 部件 | 说明 |
|---|---|
| `fjfs.rs` 背板 `rd_seg`/`wr_seg` | AHCI ready → 单扇区循环 (count>1); 否则 ATA PIO; 全 IO 点统一走背板 |
| `fjfs.rs::init` gate | `ATA_PRESENT || ahci::ready()` (原只认 ATA) |
| `vfs.rs` File.disk_name | **磁盘文件短名** (open /disk/<name> 记录; close 按真实文件名刷盘 —— 替代 M16 占位 `hello.txt`) |
| `ahci.rs::disk_read/write` | 背板原语 (virt_to_phys 恒等; 内核缓冲) |
| `sdk/linux/m135_fs.c` | T1 open /disk/f1; T2 write 15B+close (刷盘); T3 reopen read 回读一致 |
| `tools/mk_ahci.py` | **参考盘升级 4MiB** (FJFS 卷 = 2048 簇 × 2KB; 前 8 扇区参考模式) |

**实测**:
```
ahci : disk_write lba=4,5,6,7 (数据簇) + lba=1 (位图) + lba=2,3 (根目录)
fjfs : written (1 root entries)
vfs  : disk flush ok (/disk/f1)
m135: M135 RESULT: PASS  (T3: cache 15 bytes -> read 一致)
```

## 2. 踩坑 (本波)

1. **M16 占位写入名**: `fujo_close` 刷盘写死 `hello.txt` (单文件 demo 时代) ——
   任何其它 `/disk/` 文件名打开→写入→关闭后 f1 内容落进 hello.txt 记录;
   修复 = File 携带短名 (16B/项; BSS +256B);
2. **参考盘容量**: mk_ahci 原 4KB (8 扇区) 只够 AHCI 单扇区 demo —— FJFS 卷
   2048 簇 × 2KB = 4MiB; 写入分配簇递增 → LBA 越界 (盘 8 扇区, `IDNF`) ——
   **卷测试盘必须 ≥ 卷容量** (4MiB);
3. **连续写完成时序**: QEMU AIO 完成 + TFD.DRQ/BSY 需要等待 (每命令后轮询
   TFD 0x44 清); 真机盘 TRDY 延迟同场景 (aio 化完成的通用要求);
4. **栈缓冲 DMA**: 内核栈 (va=phys 恒等) virt_to_phys 直通 —— 任务页表下
   内核区恒等 map 有效 (m121 系统任务)。
