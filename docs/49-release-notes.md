# FujoOS v1.0 — 发布公告 (M100)

状态: ✅ **FujoOS v1.0.0 发布** (100 里程碑全部完成)。

## 摘要

FujoOS 是一个零第三方依赖的 x86_64 原生操作系统内核:
**内核 → 驱动 → 窗口 → 游戏层 → 开发工具链 → AI OS 独有层** 全栈自研,
全部原生原语经 QEMU 无头验证 (串口断言), 100 个里程碑逐一
实现→构建→QEMU 验证→提交推送完成。

## 发布统计

## 验收基线与数字

- 游戏层: pong 60 帧轨迹 + breakout 10 帧 (输入→渲染 avg 94µs / max 717µs);
- IRQ 合并窗口 8:1; 中断成本预算; 上下文压缩 4096→790B (19.3%);
- 性能: 帧表 avg 83ms/20M 环 (TCG 软渲染), KVM 路径预留对照 (M57);
- AI: 路由跨引擎一致 + 执行器本地/宿主双模式 + 模型卡计费/审计。

## 架构蓝图 (一句话)

```
长模式内核 (Rust, no_std, 零依赖)
 ├─ 内存/调度/异常 → 三 ABI 共存
 ├─ 驱动 (VBE/PS2/ATA/AC97/PIT) → 桌面 (wmsg/kit/输入法)
 ├─ 游戏层 (光栅/blit/着色器 VM/混音/模式) → 性能验收
 ├─ 工具链 (asm/ld/cc/调试/trace/CI) → 一键构建
 ├─ AI OS (权重页/模型卡/会话/审计/路由/执行器) → 验收
 └─ 交付 (live/安装/签名更新) → 发布
```

## 已知限制

- TCG 解释执行 (真机/KVM 10-100x 预期; M57 对照面已架);
- FJFS 多簇写往返 (M99 修复单簇读回 + ATA 写等待; 大文件补齐列入后续);
- ACPI 表体 >64MiB 未映射 (M96 guard; 表遍历列后续);
- 系统内编译器子集 (C → 单函数); GUI 无真机型设备 (参考机 QEMU)。

## 下一步 (建议)

1. KVM 对照基准 (重跑 m58/m69 同帧演示);
2. FJFS 多簇 / ACPI 高内存页表映射;
3. 系统内编译器扩展 (多函数/分支/调用);
4. 真机移植 (PCI 枚举 → 设备路径 → 显示/键盘)。
