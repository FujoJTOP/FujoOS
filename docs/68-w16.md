# 68 · W16 — 自托管编译链 (OS 内跑的 tcc + exec-from-mem/runfile 闭环)

> 里程碑: W16 (阶段三首波) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W16
> 一句话: **静态 TinyCC 在 FujoOS 内编译 C 源码并输出 ELF,
> 产物经 runfile 装载运行并打印 "tcc-compiled hello from fujo!" (m128 PASS) —
> "用自己的编译器编译并运行程序" 闭环达成。**

## 1. 交付

| 部件 | 说明 |
|---|---|
| `sdk/toolchain/tcc-static` | **自建静态 tcc 0.9.27** (WSL: gcc -static; 见 §3 构建) |
| `shell.rs` | `mbuild` (写 /tmp/hello.c → 启动 tcc 编译 argv 内核构造)、`runfile <path>` (读文件→帧→装载→运行) |
| `syscall.rs` | `exit→回 shell` (M6 升级: exit_to_shell 重设内核栈+sti+jmp; 原 halt)、`fujo_exec_mem 0x8B02`、`run_user`; 补 `lseek(8)/fcntl(72)/getcwd(79)/prlimit64(302)/memfd(318)/clock_nanosleep(228)/unix(87)`; `read(fd,NULL,0)→0` |
| `elf_loader.rs` | `load_elf_rebase`: 任意低基址静态 ELF 平移至 0x400000 (min_vaddr 对齐) |
| `vfs.rs` | `write_kernel_file` (内核态 tmpfs 写), lseek 分发 |
| `kbd.rs` | 补充 Set1 符号键 (minus/slash/dot/comma/= /;'\\)) |
| `multi 解析` | 前置到 boot (parse_multi_early): 注册表 shell 阶段可见; 主段也注册 |
| fujoregress | m128 case (mbuild+runfile 两命令注入; keys 上限验证) |

**运行链路 (m128)**:
```
mbuild: 写 hello.c (单文件 C, 内嵌 asm syscall 桥) -> tcc-static -nostdlib -static -o /tmp/hello
runfile /tmp/hello -> load_elf_rebase (delta=0) -> entry=0x4000E7 -> iretq
tcc-compiled hello from fujo!        (syscall write fd=1)
```

## 2. 关键坑 (全部证据链, 铁律 17 式)

1. **tcc 静态默认 TEXT=0x200000**: 段在 0x200000 (用户区无映射) → #PF rip=0x200000。
   `-Wl,-Ttext=0x400000` 仅移 .text, **data 段被 ELF_PAGE_SIZE=0x200000 顶到 +2MB**
   (文件 2MB > tmpfs 2048B 上限)。**定案: 改 tcc 源码 `x86_64-link.c`
   `#define ELF_PAGE_SIZE 0x1000` 重新构建** → 输出 0x400000 紧凑布局。
2. **tcc 跨对象调用走 PLT/GOT**: `hello.c + sy.o` 链接产物含 PLT stub
   (push GOT+8; jmp [GOT+0x10]), -nostdlib 无重定位 → GOT 垃圾 → 运行跳垃圾地址
   (x.x/0x200000/0x1102700000 变体), **host 上同样 segfault** (判别实验)。
   **规避: 单编译单元** — sy 桥与 _start 同文件, tcc 支持约束 a/D/S/d (不支持 'r'):
   `asm volatile("syscall" : "=a"(r) : "a"(n), "D"(a), "S"(b), "d"(c) : "rcx","r11","memory")`。
3. **fcntl(F_GETFL) 语义**: 返回 0 (O_RDONLY) 使 tcc fopen 输出流判只读 → NULL FILE 崩溃。
   返回 **0x8001 (O_WRONLY|O_LARGEFILE)**。
4. **read(fd, NULL, 0)/write len=0 必须返回 0** (tcc 解析 .o 尾部调用; -EFAULT 会污染 IO 层)。
5. **exit→shell**: 原 M6 exit=halt_forever, 编译链三步无法串行。改 exit_to_shell:
   **mov rsp,[sys_kernel_rsp]; sti; jmp shell_loop** (不 ret; 旧调用链废弃)。
   缺 sti → shell 第二次循环键盘 IRQ 全屏蔽 (按键全丢, 大坑)。
6. **静态 glibc init 面**: prlimit64(302, 写 old=RLIM_INFINITY)/memfd_create(318,-38)/
   clock_nanosleep(228,0)/unix(87,0); getcwd 返回 "/"。
7. **键盘长序列丢键 (sendkey ~90 键)**: 注入的 "tmp/sy.o" 尾部字符丢 (guest 缓冲/时序) →
   改内核命令 `mbuild` 一步完成 (避免长命令行注入)。
8. **tcc 构建**: WSL `./configure --cc=gcc; make CC='gcc -static' LDFLAGS=-static` (bcheck 的
   __malloc_hook 错误可无视, 只影响 libtcc1.a 构建; tcc 主二进制已产出)。
   **文件必须以 `-static` 链** (默认 configure 出 PIE/动态 → OS 装载 #PF rip=0x31b0)。

## 3. 构建复现 (tcc)

```bash
# WSL Ubuntu: gcc/make/curl
curl -sL https://codeload.github.com/tinycc/tinycc/tar.gz/refs/tags/release_0_9_27 -o tcc.tgz
tar xzf tcc.tgz && cd tinycc-release_0_9_27
sed -i 's/#define ELF_PAGE_SIZE  0x200000/#define ELF_PAGE_SIZE  0x1000/' x86_64-link.c
./configure --prefix=/root/tcc-out
make CC='gcc -static' LDFLAGS=-static && strip tcc
cp tcc /mnt/d/Dev/FujoOS/sdk/toolchain/tcc-static   # 1149528B
# 验证: file = ET_EXEC + ststatically linked; readelf 段 0x400000 系
```
