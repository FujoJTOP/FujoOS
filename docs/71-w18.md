# 71 · W18 — 标准软件移植 (静态 busybox 原生执行; m131)

> 里程碑: W18 (阶段三) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W18
> 一句话: **musl 静态 busybox (1.02MB) 经 argv 模式在 FujoOS 内执行原生命令
> (`os run busybox echo m131-busybox-ok`), 输出经 write(1) 落串口 —— m131 PASS。**
> 基准: M23b 已验 echo; W18 将其固化进回归矩阵 (fujoregress case)。

## 1. 交付

- fujoregress `m131-bbx` case: initrd = `sdk/busybox-musl` (alpine busybox-static);
  keys = `os run busybox echo m131-busybox-ok`; needle = `m131-busybox-ok`;
- 不需要新内核代码: shell `os run busybox <args>` (argv 模式, M23b) + musl 静态程序的
  syscall 面 (read/write/brk/mmap 匿名/mprotect 等) 已满足。

**实证**: busybox argc=3 (echo m131-busybox-ok) → 输出文本 → PASS (14/106 未实现为
sigprocmask/静默, musl 容忍)。

## 2. 溢出/限制 (文档面)

- busybox `ls` 需 getdents64 (217), `cat`/`sh` 需目录语义 — VFS 无目录树 → 限制在
  无目录命令集 (echo/env/true/...; uname 类需 stat 面已覆盖);
- 后续: 补 getdents64 + readlink → busybox ls 全通 (W18 二期)。

## 3. 踩坑

1. busybox-musl 需要 argv 模式 (否则 argc=0 → Usage); shell `os run busybox` 已带;
2. **echo 输出经 stdio 缓冲 → 需要 stdout 缓冲 mmap 匿名页 (0x802000 demand-zero)** —
   现有 mmap/demand-zero 已覆盖 (m131 日志佐证);
3. syscall 14 (rt_sigprocmask) / 106 未实现 — musl 忽略; 打印 "unimplemented" 而已。
