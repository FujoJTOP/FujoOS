## A5 可用性度量 — 定义 + 数据 (部分完成; 真机值待 C4)

- **三层时延预算定义** (新增, A5 的原"无定义"解除):
  - L1 实时层: 事件环/哨兵 = **规则优先, μs-ms** (无模型参与);
  - L2 建议层: 模型端到端 (链路+推理) = **0.08-0.6s** 实测 (7b/8b think-off, B3);
  - L3 决策层: R3 TTL 协议 **硬化** (TTL ≈ 推断耗时×2+400ms ≈ 4s) > L2 95 分位;
- **可用性判据**: 端到端时延 ≤ 决策预算 且 R3 TTL 覆盖 95 分位时延 ——
  当前链路 (7b/8b think-off ≤0.6s << TTL 4s) **成立**; 0.5b 0.05-0.2s 亦成立;
  think-on (20-47s) 不成立 → 数据驱动结论: **qwen3 系必须 think-off**;
- 真机时延 = C4 (冻结, docs/96 解除时实测)。
