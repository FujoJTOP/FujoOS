# 65 · W14a — virtio-net 驱动 + ETH/IP/UDP 全链路 (ARP 应答 + echo 往返)

> 里程碑: W14a (阶段二) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W14
> 一句话: **virtio-net legacy 驱动 (2 队列 rx/tx) + 手工栈
> (ARP 应答 + IPv4 + UDP) 打通 QEMU slirp 全链路: host 侧 echo 服务
> 回显 payload 32B, guest 校验 eth/ip/udp 全字段 PASS。**

## 1. 交付

| 部件 | 说明 |
|---|---|
| `kernel/src/net.rs` | virtio-net legacy (1AF4:1000): BAR0 I/O, 俩队列 (0=rx 1=tx), MAC 读 config@0x14, rx 预投 16 槽 [hdr(10B)+data(1514B)], 轮询 used.idx |
| `syscall` | `0x8A04 net_info` / `0x8A05 net_tx(frame)` / `0x8A06 net_rx(buf)` |
| `sdk/linux/m124_net.c` | 手搓 ETH/IPv4/UDP + ARP 应答; UDP echo 往返断言 |
| `tools/udp_echo.py` | host 侧 UDP 回显服务 (127.0.0.1:7777) |
| fujoregress | m124 用例 + case 第 6 项 = host 服务 opts (`udp_echo`/`port`) |

## 2. vring 差异 (vs virtio-blk)

QEMU `virtio-net-pci` **无 queue-size 属性** (blk 有): 默认 256 →
`desc[256]×16B` 整页 + avail@+0x1000 + used@+0x2000 (独立页)
(`virtio_queue_update_rings`: avail = desc + num*16; used = align(avail+4+num*2, 4096);
net 时 desc 表已占满首页, avail 顺延下一页) — 每队列 3 帧。

## 3. 全链路关键点 (W14a 实证)

1. **设备 MAC 默认 = 52:54:00:12:34:56 = slirp 网关 MAC** → 回显路由错乱
   (tx 后 echo 收 32B 但 guest 无回显)。处方: `-device virtio-net-pci,...,mac=52:54:00:12:34:57`;
2. **slirp 转发前 ARP 解析 guest MAC** → 必须应答 "who has 10.0.2.15"
   (ARP 帧 60B, op@eth+20, sha@22, spa@28, tpa@38 大端);
   构造 reply 后重发 UDP; demo 轮询时忽略非 IP 帧;
3. **rx 预投后需 kick** (`QUEUE_NOTIFY`=0) — guest→device 通知方向;
4. slirp: guest src 10.0.2.15, 网关 10.0.2.2 (MAC 52:54:00:12:34:56),
   guest→10.0.2.2:PORT = host 127.0.0.1:PORT; 回显帧 dst = 本机 MAC。
5. 设备 config 区 MAC @ BAR0+0x14 (与 blk 容量区同位置, 设备相关)。

## 4. 实证 (m124, 离线)

```
echo: rx 32B                    (host 收到 guest UDP payload)
m124: T1 ready=1 mac=52:54:00:12:34:57
m124: T2 tx rc=0                (设备消费 desc 链)
m124: T3 rx rc=74 verify=1      (回显帧 74B; eth dst/ip src/udp ports/payload 全对)
M124 RESULT: PASS
```

## 5. 踩坑 (本波)

1. **virtio-net-pci 没有 queue-size 属性** (blk 才有); 默认 256 → vring 布局按 3 页;
2. **设备默认 MAC 与 slirp 网关 MAC 相同 (52:54:00:12:34:56)** → tx 能出、rx 永不回
   (slirp 映射混乱); 显式 mac= 指定;
3. **slirp 转发需 ARP 应答** — 忽略 ARP 则回显永远不来 (静默丢);
4. host echo 端口被残留 python 占用 → fujoregress 内嵌 srv bind 10048;
5. ARP 字段偏移: op 大端@20, sha@22, spa@28, tpa@38 — 用网络序逐字节拷贝, 不要 put32 反转。
