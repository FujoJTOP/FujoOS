# 62 · W11 (M121) — 独立地址空间: 每任务页表链 + CR3 切换 (进程隔离)

> 里程碑: W11 (阶段二首站) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W11
> 一句话: **每任务私有页表链 (PML4→PDPT→PD→PT0/PT1) + 调度切换 CR3 ——
> 同 VA 不同物: 派生任务堆区各归其主 (进程隔离), fork 堆页物理拷贝 (语义正确),
> munmap 撤销补全; 系统/隐式任务保持静态表 (逐字节兼容)。**

## 1. 设计

| 机制 | 内容 |
|---|---|
| 页表链 | 每任务 5 帧: PML4/PDPT/PD/PT0/PT1。PML4/PDPT/PD 拷贝系统链 (身份映射共享, 内核页 U=0 不动); PD[4]/PD[5] 换私有堆 PT (P=0 → 按需零页) |
| shm 契约 | 每任务 PT1[0] 钉 0xA00000 (FJSH 物理恒等) —— shm-link 全局共享 (M112 不变) |
| CR3 切换 | `fujo_tick_sched` / `terminate_current_and_next` 切换点: `mov cr3, task.cr3` (0=系统) |
| 兼容 | 系统/隐式任务 (cr3=0) 用静态 PT_HEAP0/1 —— 引导 CR3 与旧行为逐字节不变; spawn_proxy 桌面代理保持系统表 |
| fork | 子任务独立链 + `as_copy_heap`: 父堆已映射页**物理拷贝** (同 VA 同值, 各享帧; shm pin 页共享) |
| mmap 撤销 | `munmap` 由 v0 no-op 补全: 堆区清 PTE + 释放帧 + invlpg (0xA00000 pin 保留) |
| 调试 | `0x830E fujo_cr3_probe(out)`: [当前 CR3, 引导 CR3] |

派生面: fork 子 / spawn_tasks (M13 双任务) / exec_spawn aux (cap_exec LAUNCH) /
窗口任务 (spawn_at);每任务 +24B × MAX_TASKS 的 Task 字段,页表帧从帧池分配 (6 帧/任务)。

## 2. 实证 (m121_isol, 离线, 入 fujoregress)

```
隐式 0x800000 = 0x5A5A5A5A
worker (私有 CR3=0x1001000): saw=0 (同 VA 读不到器主值 -> 按需零页各归其主!)
                           -> 写 0xDEADDEAD
隐式复读 own=0x5A5A5A5A (worker 的写不可见)          [隔离 ✓]
fork 子: child saw=0x5A5A5A5A (堆页拷贝) -> 写 0xCAFE
父复读: 仍 0x5A5A5A5A                                  [拷贝✓ 隔离✓]
munmap: mmap 2 页 -> 写标记 -> munmap -> 重读 0        [撤销✓]
M121 RESULT: PASS
```

## 3. 踩坑 (本波实证, 必有教训)

1. **`mov {}, cr3` 是"读"不是"写"**:切换 CR3 必须 `mov cr3, {}`。误写成读方向后
   (沿用了 mem.rs 既有 `write_cr3_flush` 的错误模板 —— 该函数也是空操作,
   靠 invlpg 兜底而未暴露), worker 始终跑引导 CR3 → 表链正确但全共享,
   探针 `0x830E` 回读 CR3=0x102000 才定位。**修三个点**: switch_cr3 (新) +
   write_cr3_flush (存量修正, 行为只变好)。
2. **页面视图 vs 域视图混淆**: 判"隔离是否生效"必须核 **CR3 回读 + 页表链回走**
   双证据 —— 只看 walk 表链会误判 (链对而 CPU 未用)。
3. **根目录 cargo build 只编 tools (铁律 1)**: 调试轮里连续两次产物未更新
   (0.05s "Finished" = tools), 探针"没打出来"实为旧内核。
4. **轮询让出时序**: 2000 次快速轮询 <1ms, 派生任务无分片 → 握手超时假 FAIL;
   改 200000 次 (~0.3s, PIT 轮转保证子任务运行)。

## 5. 不做 (记录)

- 未做 **COW** (copy-on-write fork —— 现为物理拷贝, 8 任务规模可接受);
- 未做虚拟地址空间重定位 (进程仍固定装载 0x400000/0x1000000;
  W12+ 的独立进程 + loader 再论);
- 未做页表回收 (kill/exit 时帧泄漏 —— 帧池 47MB, 目前可接受, 记录为欠账);
- m108 高区映射的 per-task PD 快照时机: 若窗口任务在 map_high_user 之前
  spawn 则缺高区 (当前流程 map 先于 spawn, 行为正确)。
