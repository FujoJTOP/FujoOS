## 3. 系统级结论 (论文 §8 新增)

1. **模型边际价值 = 规则边界外** (两职责实证 +2/+2), 边界内 = 0 (蒸馏优先正确);
2. **模型规模阈值**: 0.5b 不可用 (all-RUN), ≥7b 才有 novel 增量 —— 质量-规模曲线首个实测点;
3. **blast radius 定理**从断言升级为可复现实验 (对抗注入实测);
4. **自我进化闭环**完整: 在线命中 → 候选 → bake → 重编 → 调用率下降 (~38→≤1/0);
5. **职责所有权**由实测判定, 非设计假设 (io 基线夺回);
6. **器官感知自身**: 哨兵由真实事件环驱动 (非 demo 文本), 处置效果可测 (99→0)。
