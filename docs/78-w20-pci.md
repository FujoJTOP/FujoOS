# 78 · W20 p7 — PCI 枚举完整化 (多功能设备; m137)

> 里程碑: W20 p7 (脱 QEMU 专属) · 上游: docs/74 审计表 #11
> 一句话: **`scan_all` 从"每 slot 只扫 func0"升级为"逐 func 独立"—— Q35 SATA
> (31.2)、SMBus (31.3) 等真机常见多功能设备全部入列; 0x8503 条目加 func 字段
> (bit48-55); m137 PASS (devices=6, SATA func=2 定位)。**

## 1. 交付

| 部件 | 说明 |
|---|---|
| `acpi.rs::scan_all` | 多功能遍历 (3 总线 × 32 slot × 8 func; 每 func 独立判活) |
| PCI_BUF 编码 | `vid(0-15)|did(16-31)|bus(32-39)|slot(40-47)|func(48-55)` (向后预留) |
| `sdk/linux/m137_pci.c` | T1 devices≥5 / T2 SATA 8086:2922 func=2 / T3 host func=0 (q35) |
| `tools/fujoregress.py` | m137-pci 用例 (**-machine q35**) |

**实测** (QEMU 9.2 q35):
```
pci  : scanned 6 devices (multifunc)
m137: T1 devices=6 ok  T2 sata ok  T3 host ok
m137: M137 RESULT: PASS
```

## 2. 踩坑

1. **原枚举只有 4 设备** (Q35 主机桥/VGA/网络/ISA = func0-only) ——
   SATA(31.2)/SMBus(31.3) 从未进入 0x8503 审计面; 真机几十设备 = 大多 func0
   但多功能 slot 普遍 (桥/控制器);
2. **枚举与查找双路径**: `pci_find` (W20 p4 已修) 与 `scan_all` 曾各自独立逻辑 —
   本次统一为"逐 func 独立判活"模式 (避免再分叉)。

## 3. 审计表更新 (#11)

**✅**: PCI 枚举/查找均多功能完整; q35 对照 monitor `info pci` 一致 (6 设备)。
