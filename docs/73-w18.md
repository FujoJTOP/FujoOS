# 73 · W18 二期 — VFS 目录语义 + busybox 目录命令 (getdents64; m132)

> 里程碑: W18 (阶段三) · 上游: [57-long-roadmap.md](57-long-roadmap.md) W18 · 前置 W18 一期 (m131 busybox echo)
> 一句话: **stat 类型语义 (目录/文件) × open(O_DIRECTORY) × getdents64 目录枚举 ——
> 静态 busybox 的 `ls` 全目录系列原生命令在 FujoOS 内完整运行 (m132 PASS)。**

## 1. 交付

| 部件 | 说明 |
|---|---|
| `vfs.rs::fujo_stat_path` | stat 真实语义: 目录 → S_IFDIR\|0755; tmpfs → REG+size; 设备 → CHR; 未知 → -ENOENT; `.`/`..` 后缀规范化 (busybox 对每条目 stat 相对路径); `/` 根目录 |
| `vfs.rs::F_KIND_DIR` + open 目录分支 | `open("/tmp")` 等固定目录表 → 目录 fd (枚举游标在 `File.pos`) |
| `vfs.rs::fujo_getdents` / `next_entry` | nr 217: linux_dirent64 流 (d_ino/d_off/d_reclen/d_type/name), reclen=align8(19+n+1); `/` 7 子目录, `/tmp` 8 槽, `/dev` tty/model0/null, `/proc` meminfo, `/boot` module, `/lib` 注册库 |
| `vfs.rs::tmpfs_lookup` | 只读查找 (stat 不得创建文件; 只读语义) |
| `vfs.rs::fujo_fstat_mode` | fstat 目录 fd → DIR (tree 视图一致) |

| `sdk/linux/m132_dirs.c` | T1 stat=/DIR, T2 open O_DIRECTORY, T3 getdents 含 . .. hello.txt, T4 stat=REG, T5 /dev 枚举 → M132 PASS |
| `tools/fujoregress.py` | m132-dirs 用例 (不注入, 自动跑) |
| `scripts/build-samples.ps1` | m132_dirs 入重建清单 |

**实测** (busybox musl 静态, `os run busybox ls ...`):
```
os> os run busybox ls -a /tmp
.
..
hello.txt
user : sys_exit code=0
```
批量: `ls /` → boot dev disk lib proc runres tmp; `ls /proc` → meminfo; `ls /dev` → model0 null tty; `ls /boot` → module —— **零 "No such file" 错误** (busybox 对每个条目 stat 相对路径, errno 通路完全干净)。

## 2. 调试链 (trace 驱动)

1. **unimplemented 打印只一次 (c<=3)** 掩盖了 217 的缺失 —— 开内核 TRACE (0x5301 常开 + exit 自动 dump) 拿到完整调用面: busybox ls = stat(4) → open(2) → fcntl(72) → mmap(9)→ **getdents64(217)** → close(3) → munmap(11);
2. **stat 无脑 REG** → busybox 认为 `/tmp` 是文件, 打印路径 exit 0 —— 目录语义缺失的假象 ("busybox 已能跑") — **trace 打印 a0 值并对照系统调用表** (stat a0=字符串地址 / getdents a0=fd) 区分参数;
3. **分发参数错位**: `217 => fujo_getdents(a1,a2,a3)` —— getdents64 的 fd 在第一参数! openat(257) 才该转发 a1 (path 是第 2 参)。教训: **每个 syscall 的分发参数索引按 ABI 第 N 参, 不做"一律前移"假设**;
4. **路径 "./.." 语义缺失** → "ls: /tmp/..: No such file or directory" 但列表仍出 — busybox 对每条目 stat 相对路径; stat 加 `strip_suffix("/."|"/..")` 递归解析;
5. **调试审计**: TRACE_ON=1 + exit trace_show 为纯调试改动, 验收后已移除 (当前 0)。

## 3. 踩坑

1. getdents64 的 **d_reclen 对齐** (19+n+1 → 8): 假设 32 对齐会被 musl 的 dirent64 步进解析错 (m132 解析器按 d_reclen 步进, 是对齐规则反例);
2. **stat 到不存在路径必须 -ENOENT** (旧实现"见啥都 REG 成功"); busybox 的 foreach 会报错但不退出 — **错误消息本身是功能性信号**;
3. fujo_stat_path 拒绝创建 (tmpfs_lookup 只读): stat("/tmp/x") 不得副作用;
4. open 目录 fd 的 `f.name = name` 生命周期: File.name 是 `&'static str` · 目录固定表 → match 静态字面量。
