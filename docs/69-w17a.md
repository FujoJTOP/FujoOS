## 2. 卡点 (QEMU 9.2 TCG, -smp 2)

- **现象**: ICR 写回读 0x608 ✓, monitor `info lapic` 显示 SPIV=0x1FF + ICR=0x608 (physical, no-shorthand), **但 AP 不执行 0x8000** (执行标记 @0x8230 与完成标记 @0x8220 均 0);
- **INIT 变体**: 写 ICR=0x500 (INIT) 后 **BSP 冻结** (log 停在 "SIPI ->" 之后; thread=single 时缓解为 delay 后仍无 marker);
- **候选**: ①INIT 值/触发模式 (0x500 vs 0x4500 vs level) ②TCG AP 冷启动状态 (reset vs WFS) 需 INIT 语义精确匹配 ③dest 编码 ④-accel tcg,thread=single 下虚拟 TSC 推进;
- **下波动手**: 在 QEMU 源码 (hw/i386/apic.c / tcg) 或 Linux AP 启动序列 (`arch/x86/realmode`) 对照; 或用 `-device kvm-ioapic`? (KVM 无); 或退 **virtio-ramfb? 无关** — 主路径 = 对照 Linux `smpboot.c` INIT-SIPI 时序 (ICR 值/延时/两次 SIPI);
- **单核无回归**: ap_bringup 仅在 ncpu>=2 执行 (cpuid 探测), 单核分支直返。

## 3. 踩坑 (本波)

1. **PDPT[3] 是 LFB 与 LAPIC 共享的页目录**: 替换 pdpt[3] 整链 = 0xFD000000 写 #PF (gfx logo 崩); 必须复用旧 PD, 只插 PD[503]→PT[0];
2. **LAPIC SVR (0xFEE003F0) 必须先软件使能** (bit8=0x1FF): 否则 ICR 写入不交付 (QEMU monitor 佐证: 写后 SPIV=0x1ff);
3. **INIT ICR 在 TCG 下冻结 BSP** (见 §2);
4. **trampoline 生成**: clang -m16 + `ld.lld --oformat=binary -T 脚本`; 跨 section 差值 (`.rodata` label) clang 报 "Cannot represent a difference across sections" → **全部放 .text 一个 section**;
5. **16 位 trampoline 用 bp+disp8 寻址** (lgdt/marker) — 先 `mov $0x8000,%bp`;
6. **rdtsc 忙等在 TCG 多核下虚时钟推进不确定** — 延时用短 tick 或改 port 轮询。
