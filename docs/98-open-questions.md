## A. 毫无头绪（6 项 · 知识边界上的洞）

### A1. 接口证明的形式化本体（立论级）
- **状态**: 无头绪。A1–A4 是断言测试而非证明; 想形式化时找不到映射（模型=黑盒、
  事件环=并发、域=可变状态; 现有形式化 OS 全部假定确定性组件）。
- **卡点**: "核/面"（域门/审计 = 核, 模型行为 = 面）是自造词, 无文献锚点;
  不知道该证明什么、用什么逻辑系统。
- **依赖**: 文献输入（zcode 核对时留意）或评审攻击; 接受为论文"诚实边界"。
- **线索**: 无。

### A2. "未发现的语义反转"冰山大小（工程认识论）
- **状态**: 无头绪。W17 (ICR 低写) → W29 (WHPX APIC-only) → W31 (嵌套 KVM LAPIC 不可用)
  —— 每个新执行模式揭露第 N+1 条审计表项。无法估计总量。
- **卡点**: 无手段估计"还有多少宽化的硬件语义"（未知未知）。
- **候选方向**（不成熟）: 逐设备对账 / 差分测试（TCG vs KVM 同操作序列对比）——均未验证有效。
- **处置**: 接受为研究边界; 审计表"发现一条打一条"策略继续。

### A3. 立论困境: 域拦截兜底后, "模型质量"对"AI OS 安全"的意义
- **状态**: ✅ **有头绪（zcode 框架, 2026-09）→ 降级为 B 类实现项 "信任自适应域"**。
- **zcode 拆解**: "安全"不是一词而是三物 —— α 越界（域门/机制·可达性命题 S1）、
  β 边界内坏状态（委托命题 S2·被委托人能力, 未防护=设计决定而非缺口）、
  γ liveness 劣化（调度/资源命题）; blast-radius 保证的是 α（动作可达集有界）,
  不是"系统不变坏"; 模型负责 β/γ: 机制决定"能走多远", 质量决定"走到哪、停不停"。
- **安全主张 = 三个并立命题**: S1 机制（实测动作集⊆域∩授权·可证明） ×
  S2 委托（n=19 度量盲区覆盖度, 是质量不是安全） × S3 政策（边界由人/蒸馏规则画）。
- **技术收口 = 信任自适应域**: 每 duty 质量台账（滚动窗口命中率/谬误率）→
  `dom_admit()`: 质量≥τ_high → 域加宽; <τ_low → 域收缩（回归仅规则/最低权限）;
  域表变化走 cap_exec+审计（A1/A2 管住"谁来扩域"）——
  「AI OS 安全」= α 无越界 × 域宽 = f(测量质量)。
- **工程**: M116 域表 + dom_admit + 质量台账 三样已有两样（剩 dom_admit 接合）;
  见 docs/99（信任自适应域专用档）。

### A4. 系统内归纳: "自治进化"工程可行性
- **状态**: 无头绪。程序合成（确定性, 落地）→ 退化为非 LLM 进化; 内置小模型 →
  BSS 余量 13KB 不可能; 统计学习 → 又非"LLM 驱动"。无第三条路。
- **卡点**: "自治进化"概念本身待定义（与 A3 同根: 模型在系统里的角色）。
- **依赖**: 无已知线索; 接受为半自治边界（docs/81 Discussion 已声明外部归纳步骤）。

### A5. "第一可用"的时延度量
- **状态**: 无头绪。真机链路 = COM2 115200 + 本地推理秒级; 从未测端到端, 从未定义
  "多快算可用"。候选（100ms/1s/仅非实时决策）各有问题（非实时决策又回 A3）。
- **依赖**: 真机硬件（C 类）+ 度量定义（立论）。
- **处置**: 冻结项（ds/96 硬件波解除时顺带实测; 度量定义随 A3）。

### A6. 第二代系统（Loment）形态 + "该不该动态化"
- **状态**: 无头绪/价值排序问题。BSS 近上限、全静态分配 → "该建第二代"是信号无蓝图;
  动态化 vs "小型可验证"（本项目价值）冲突; 不确定该不该。
- **处置**: 列为超长期议题; 论文期内不推进。
