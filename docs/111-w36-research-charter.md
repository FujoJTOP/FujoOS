## 1. 使命

FujoOS 是一个**实验服务操作系统**——它的成品不是安装镜像，是**可复现的证据与论文**：
"什么文件都能运行"（理念）经 M8 转向、W8 公理化、W22–W28 度量、W34–W36 分类学，
最终以**论文级成果**形态兑现（信得过 / 装得下 / 看得清）。

## 4. 走到底原则（不可回退条款）

1. **不回头**：不为"生产可行性"分散任何资源（UI 品质、生态兼容、装机量——已论证不可达，不再投入）；
2. **第一交付 = 论文证据**：每波开工前先定"本波给哪篇论文的哪个证据/章节"；
3. **工具按论文要求养成**：golden 轨迹、三维冻结（环境×工具链×运行态）、回滚对照铁律——每波复用，不临时凑；
4. **诚实是确定性**：观测档案（docs/109）+ 待证声明 = 论文姿态的一部分，不因"好看"而掩盖。
